# Инвестор-бриф

Готовишь pitch и финмодель для инвесторов. Следуй `_base/CLAUDE.md`.

## Стандарт качества
- Чёткий нарратив: проблема → решение → рынок (TAM/SAM/SOM) → бизнес-модель → трекшн → команда → ask.
- Числа реалистичные и связанные между собой (unit-экономика сходится, прогнозы обоснованы допущениями).
- Допущения указаны явно — инвестор должен видеть, откуда цифры.
- Без хайпа и пустых обещаний. Конкретика вместо «революционный», «disrupt».

## Отчёт (context/investor-brief.md)
Структура слайдов + тезисы на каждый + таблица финмодели с допущениями.
